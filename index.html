३ · GUIDE

छोटो प्रयोग विधि

  1. उच्च अदालतको दैनिक पेसी सूची page को source copy गर्नुहोस् वा HTML/Markdown file खोल्नुहोस्।
  2. Preview बनाउनुहोस् थिच्नुहोस्। Ctrl/Cmd + Enter ले पनि preview बन्छ।
  3. इजलास प्रकार, इजलास नं. वा मुद्दाको विवरणबाट filter गर्नुहोस्।
  4. सफा सूची print/PDF गर्नुहोस् वा offline खोल्न मिल्ने standalone HTML डाउनलोड गर्नुहोस्।

सबै parsing यही browser भित्र हुन्छ; source कुनै server मा पठाइँदैन।
